# Bashment User Stories

## Patrons

### Event Discovery

As a patron, I want to discover nightlife and cultural events near me so that I can find experiences that interest me.

### Event Information

As a patron, I want to understand key event information so that I can decide whether an event is relevant to me.

### Activity Signals

As a patron, I want to understand activity around an event so that I can make a more informed decision about where to go.

### Location

As a patron, I want to see events geographically so that I can understand what is happening around me.

---

## Promoters

### Event Creation

As a promoter, I want to create an event so that potential attendees can discover it.

### Event Management

As a promoter, I want to manage my event information so that details remain accurate.

### Event Visibility

As a promoter, I want visibility into activity surrounding my event so that I can understand engagement.

### Event Intelligence

As a promoter, I want access to event intelligence so that I can make better promotional decisions.

### Forecasting

As a promoter, I want attendance-related forecasts so that I can better understand potential event performance.

---

## Venues

### Event Visibility

As a venue, I want visibility into events and activity at my location so that I can better understand venue performance.

### Attendance Intelligence

As a venue, I want attendance-related intelligence so that I can make better operational decisions.

### Performance Insights

As a venue, I want event performance information so that I can identify opportunities for improvement.

---

## Intelligence

### Explainable Forecasts

As a user, I want to understand why a forecast was generated so that I can evaluate whether the information is useful.

### Confidence

As a user, I want to understand the confidence associated with a forecast so that I can assess how much weight to give it.

### Recommendations

As a user, I want intelligence translated into recommendations so that I can take action rather than simply view data.

### Continuous Improvement

As a product team, we want to compare forecasts against actual outcomes so that future forecasts can improve.

---

## Beta Learning

### Feedback

As a beta user, I want an easy way to provide feedback so that the product can improve based on my experience.

### Product Improvement

As the product team, we want to analyze beta behavior and feedback so that product priorities are informed by real-world evidence.

### Signal Discovery

As the product team, we want to analyze completed-event data so that we can identify signals that may improve future forecasting.
