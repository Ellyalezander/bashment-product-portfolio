# Bashment Technical Stack

## Overview

Bashment uses a combination of web platforms, data services, APIs, mapping technology, and development tools to support product delivery and beta testing.

The technology stack is evolving alongside the product.

---

## Development & Version Control

### GitHub

Used for source control, repository management, documentation, and technical portfolio development.

---

## Application & Deployment

### Vercel

Used for web application deployment and hosting.

---

## Backend & Data

### Supabase

Used to support backend, database, authentication, and data-related capabilities.

### SQL

Used for querying, analyzing, and working with structured data.

---

## Mapping & Location

### Mapbox

Used to support map-based and geolocation experiences within Bashment.

---

## Integrations

Bashment is designed to work with APIs and third-party services to support:

- Event data
- Location data
- Authentication
- Product functionality
- Intelligence capabilities

---

## Authentication

### OAuth

Used where appropriate to support secure authentication and integration workflows.

---

## AI & Intelligence

AI APIs may be incorporated into the intelligence layer to support product capabilities.

The intelligence strategy does not rely solely on generative AI.

The initial forecasting approach prioritizes transparent statistical and baseline methods, with more advanced machine learning considered as sufficient real-world data becomes available.

---

## Technical Stack Philosophy

Bashment's technical approach prioritizes:

- Rapid iteration
- Maintainability
- Data quality
- Explainability
- Scalable foundations
- Measurable outcomes
- Avoiding unnecessary complexity during the MVP stage

Technology decisions should support the product objective rather than introduce complexity for its own sake.
