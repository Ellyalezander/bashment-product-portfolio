# Bashment MVP Scope

## MVP Objective

Validate the core Bashment experience with real users while establishing the data foundation required for future intelligence capabilities.

The MVP prioritizes product validation, usability, data collection, and measurable outcomes.

---

## In Scope

### User Experience

- User onboarding
- Event discovery
- Location-based event experience
- Event information
- Event activity
- Beta feedback

### Promoter Experience

- Promoter onboarding
- Event creation
- Event management
- Event visibility
- Basic event performance information

### Intelligence Foundation

- Event data collection
- User activity signals
- Location signals
- Engagement signals
- Baseline attendance forecasting
- Forecast explanations
- Confidence indicators
- Forecast-versus-actual measurement

### Technical Foundation

- Authentication
- Database
- API integrations
- Mapping
- Deployment
- Analytics and measurement
- Beta environment

---

## Out of Scope for Initial MVP

The initial MVP does not require:

- Fully automated machine learning
- Complex predictive models
- Large-scale market expansion
- Fully automated recommendations
- Advanced venue analytics
- Extensive third-party integrations

These capabilities can be evaluated as product data and user validation increase.

---

## MVP Success Criteria

The MVP should demonstrate that Bashment can:

1. Attract and onboard beta users.
2. Provide useful event discovery.
3. Support promoter event workflows.
4. Collect meaningful event and behavioral data.
5. Establish initial intelligence signals.
6. Produce transparent baseline forecasts where sufficient data exists.
7. Compare forecasts against actual outcomes.
8. Use beta findings to prioritize future product improvements.

---

## Guiding Principle

The MVP is successful when it produces **validated learning and measurable product value**, not simply when additional features are added.

**VALIDATE → MEASURE → LEARN → IMPROVE**
